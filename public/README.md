# iraigpt.ir

سایت چت هوش مصنوعی شبیه ChatGPT که روی خود سرور سایت اجرا می‌شود و پاسخ‌ها را از طریق یک مدل زبانی (مثلاً OpenAI) تولید می‌کند.

## پیش‌نیازها

- نصب Node.js (نسخه ۱۸ یا بالاتر پیشنهاد می‌شود).
- داشتن کلید API برای مدلی که می‌خواهید استفاده کنید (در حال حاضر مثال با **OpenAI** پیاده شده است).

## نصب و اجرا

در پوشه‌ی پروژه (`iraigpt.ir`) این دستورات را اجرا کنید:

```bash
npm install
npm run start
```

سایت روی آدرس زیر در دسترس خواهد بود:

```text
http://localhost:3000
```

> توجه: قبل از اجرا، متغیر محیطی `OPENAI_API_KEY` را با کلید OpenAI خود تنظیم کنید تا مدل روی سرور بتواند پاسخ بدهد.
